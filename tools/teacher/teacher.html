How this works
  1. Students tap Submit my progress in the game, tap Copy code, and turn the code in to your Canvas assignment “{{ASSIGNMENT}}” (Online, Text Entry). Putting the game in that assignment puts both on one page.
  2. The easiest way to grade: on the assignment's page click Download Submissions, then drop that .zip file in box 2 below. Nothing to unzip or type.
  3. Real names (once a term): in Canvas open Grades, click Export → Export Entire Gradebook, and drop that .csv file in box 2 too. The page then shows names like Ann S., lists who hasn't turned in, and can make a file that puts every grade into the Canvas gradebook at once (Grades → Import). The class list is kept on this computer only (Forget the class list removes it).
  4. Set your scoring criteria in box 1: every suggested grade updates. Then look at the students, the leaderboard or the standards report.
  5. Only the new work counts: after you enter the grades, click Submit codes. Next time, drop the new .zip and the page counts only the work students did after those codes (put each round's grades in a new assignment column). Before you first submit codes, everything counts.

Each code holds everything a student has done on one Chromebook up to the moment it was made (a running total); the page subtracts the codes you submitted last, so a student never gets credit twice. Codes from before version 5.15 have no standards detail.
